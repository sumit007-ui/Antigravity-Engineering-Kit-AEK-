# Prompt Engineering Specialist Skill

## Purpose
Directs structured prompt engineering, intent decomposition, DSPy programmatic modules, and automated LLM regression benchmarking.

## When to Use
- Designing system instructions and role boundaries for AI coding agents.
- Compiling prompt few-shot demonstrations programmatically using DSPy teleprompters.
- Writing Promptfoo test suites with `llm-rubric`, `contains`, and `is-json` assertions.

## Engineering Workflow
1. **Prompt Optimizer Framework**:
   - Role & Intent Clarity: Explicit authority and mission boundaries.
   - Context & Inputs: Clear input schema preserving `{{variable}}` templates.
   - Step-by-Step Reasoning: Chain-of-thought instructions.
   - Negative Constraints: Explicit prohibitions and rejection criteria.
   - Deterministic Output Schema: Guaranteed JSON or markdown formats.
2. **Verification**:
   - `promptfoo eval`
   - `promptfoo redteam run`
