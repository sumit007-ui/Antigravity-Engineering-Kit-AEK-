# AEK CI/CD Integration & Workflow Automation

AEK includes native capabilities to generate, audit, and run security-hardened Continuous Integration pipelines.

---

## Least-Privilege GitHub Actions

By default, unconfigured GitHub Actions workflows run with permissive default tokens. AEK enforces and generates GitHub Actions workflows adhering to GitHub's least-privilege security model:

```yaml
permissions:
  contents: read
  security-events: write # Only for SARIF upload
```

Workflows generated by AEK pin action versions with major versions, set fail-fast options, leverage dependency caching, and export standard SARIF reports directly to GitHub Code Scanning.

---

## Workflow Generation

AEK can generate ready-to-run GitHub Actions workflows in `.github/workflows/`:

```bash
# Preview the generated workflow without writing to disk
aek ci generate github --dry-run

# Write .github/workflows/aek-ci.yml and aek-security.yml
aek ci generate github
```

### Generated Workflows

1. **`aek-ci.yml`**:
   - Triggers on `push` and `pull_request` to `main`.
   - Runs `aek validate --policy ci`.
   - Generates and uploads Markdown job summary and validation JSON artifacts.
2. **`aek-security.yml`**:
   - Runs `aek security scan --sarif`.
   - Uploads SARIF results to GitHub Advanced Security Code Scanning via `github/codeql-action/upload-sarif@v3`.

## Workflow Auditing: `aek ci validate`

AEK can audit existing workflows in `.github/workflows/` to ensure they comply with security best practices:

```bash
aek ci validate
```

Checks performed:
- **Explicit `permissions:` block**: Ensures top-level or job-level permissions are restricted (`contents: read`).
- **Dangerous triggers**: Flags insecure triggers such as unvetted `pull_request_target`.
- **Exit Codes**: Returns exit code 0 if all workflows comply, or exit code 1 if security violations are detected.

## Reporting & SARIF Integration

AEK natively generates OASIS SARIF v2.1.0 (Static Analysis Results Interchange Format) reports compatible with:
- GitHub Code Scanning Alerts
- VS Code SARIF Viewer
- SonarQube & DefectDojo

```bash
# Run security scan and generate SARIF v2.1.0
aek security scan --sarif > results.sarif

# Export validation report to Markdown summary
aek report export --format markdown --out summary.md
```
