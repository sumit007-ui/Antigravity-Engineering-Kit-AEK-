# Antigravity Brief — UI/UX Redesign & Asset Pipeline

## Style Bible
- **Grid:** 320x180 base canvas (upscale nearest-neighbor only)
- **Palette (16 colors):** `#050505 #120D24 #2B1544 #5A1F55 #A02F58 #E0553F #FF4B18 #FF8A3D #FFC15E #FFD36B #F5E9C8 #6A2459 #3B2418 #7A4630 #98B4D4 #F4F4EE`
- **Edges:** Hard pixel edges, no anti-aliasing, no soft blur, no glows.
- **Shading:** Ordered dithering, max 3 tones per surface.
- **Composition:** Strong silhouettes, clear horizon, dark negative space for typography.
- **Rules:** Never put text inside generated images; render text in HTML/SVG using Space Grotesk, JetBrains Mono, or Press Start 2P.
